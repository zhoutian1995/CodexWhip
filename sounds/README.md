# CodexWhip Sounds

The four WAV files in this directory are deterministically synthesized by
`scripts/generate-whip-sounds.js`. They are original project assets covered by
the repository MIT license and do not contain third-party recordings.

- `leather.wav`: long leather whip whoosh and crack
- `flogger.wav`: layered multi-tail impacts
- `chain.wav`: metallic chain impact and ring
- `cyber.wav`: electrical cable zap
